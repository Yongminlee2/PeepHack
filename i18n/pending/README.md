# 잠시 빼 둔 번역 (12개 언어)

2026-10-11 에 챕터 1~5 기준으로 다 옮겨 둔 번역이다. 게임이 완성될 때까지 앱에서 뺐다.
그동안 문장이 바뀌어도 한국어·영어만 고치면 된다.

되돌릴 때:
1. `ko.json` 과 비교해 새로 생기거나 바뀐 열쇠만 다시 옮긴다.
2. 파일을 `i18n/` 로 옮긴다.
3. `python ../common/i18n/audit.py i18n` → 확정 0
4. `python ../common/i18n/gen.py i18n --to flutter --out lib/l10n`
5. `flutter test` (모든 언어가 같은 열쇠를 가졌는지 본다)
