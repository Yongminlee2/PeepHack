# 아이폰 테스트 방법 (출시 전)

앱스토어에는 아직 아무것도 만들지 않았다(앱 등록·업로드 전). 폰에서 직접 해 보고 괜찮으면 `앱스토어-작성내용.md` 0번 순서대로 낸다.

## 1. 폰에 깔기 (맥에 USB 로 연결)

```bash
cd ~/work/PeepHack
~/flutter/bin/flutter build ios --release
xcrun devicectl list devices                       # 내 아이폰 Identifier 확인
xcrun devicectl device install app --device <Identifier> build/ios/iphoneos/Runner.app
```

출시판(release)과 같은 모습이다(디버그 전용 기능 없음). 처음이면 폰의 설정 → 일반 → VPN 및 기기 관리에서 개발자 앱을 신뢰해야 열린다.
진행 기록을 지우고 처음부터 보려면 앱을 지우고 다시 깐다.

## 2. 아이폰에서 꼭 볼 것 (시뮬레이터로는 확인이 안 되는 것)

2026-10-14 맥에 꽂힌 아이폰 16 Pro 에서 `tools/device-test/run.sh` 로 확인한 것(✅). 사람이 직접 봐야 하는 것만 빈칸이다.
- ✅ 첫 실행 → 「하는 법」 카드(작전·브리치·사건 파일) → 첫 임무 따라 하기(빛나는 칩)로 끝까지 → 결과 → 다음 임무(영어)
- ✅ 키보드: 비밀번호 칸이 열리면 영문 자판이 저절로 올라오고 지도가 접힌다. `it's "ok" -- test` 를 쳐서 칸의 값이 그대로(둥근 따옴표·긴 줄표·첫 글자 대문자로 안 바뀜)
- ✅ 틀린 비밀번호 → 명령 입력으로 돌아감, 맞는 비밀번호 → 접속
- ✅ 홈으로 나갔다 돌아오면 임무 화면 그대로
- ✅ 사건 자료에서 왼쪽 끝 쓸기 → 사건 화면으로
- ✅ 한국어로 켜기
- 시험 뒤 앱을 지우고 처음 상태로 다시 깔아 두었다(폰에 HackQuest 1.0.0(1) 개발 서명판).


- [x] **키보드** — 3장부터 키보드로 친다. 영문 자판으로 뜨는지, `'` `"` 가 둥근 따옴표로 안 바뀌는지, 첫 글자가 대문자로 안 바뀌는지
- [ ] **비밀번호 칸** — 아이폰 「암호」 자동 완성 줄이 거슬리지 않는지
- [ ] **소리** — 효과음·배경음악. 다른 앱 음악을 틀어 둔 채 켜면 음악이 안 끊기는지, 무음 스위치를 켜면 조용한지
- [ ] **진동** — 칸 누를 때·목표 완료·실패
- [ ] **화면** — 노치·홈 막대에 가리는 단추가 없는지, 키보드가 열리면 지도가 접히고 입력줄이 보이는지
- [x] **뒤로 가기** — 화면 왼쪽 끝에서 오른쪽으로 쓸면 앞 화면으로 간다(안드로이드 뒤로 단추와 같은 동작). 임무 중에 실수로 나가지 않는지
- [ ] **앱 전환** — 홈으로 나갔다 오면 음악이 멈췄다 이어지는지
- [x] **언어** — 폰 언어가 영어면 영어로 뜨는지, 설정에서 바꾸면 바로 바뀌는지

시뮬레이터에서는 이미 확인함: 아이폰 SE(작은 화면)·17 Pro Max 에서 27개 화면 × 한국어·영어 글자 넘침 없음(`tool/ios_screen_tour.sh`),
전체 단위 시험, 서명된 출시 ipa 만들기(`tool/ios_archive.sh`).

## 3. 고칠 것이 생기면

Dart 코드는 안드로이드와 같은 코드다 — 고치면 두 플랫폼에 같이 들어간다. 아이폰만 다른 곳은 README 「아이폰」 절.
화면을 바꿨으면 `tool/ios_store_shots.sh` 로 스토어 스크린샷을 다시 찍는다.
