# 단어 추리 + 사건 파일 설계 (재미 개편 3단계)

작성 2026-10-11.

## 단어 추리 (폴아웃 단말기 해킹과 같은 규칙)

- 메모리 덤프(기호 사이에 같은 길이의 영어 단어들이 박혀 있는 화면)에서 비밀번호 후보를 누른다.
- 틀리면 **일치 n** = 정답과 같은 자리에 같은 글자가 몇 개인지 알려 준다. 기회는 4번.
- 덤프 안의 짝 맞는 괄호 `( )` `[ ]` `{ }` `< >` 를 누르면 보너스: 틀린 후보 하나를 지운다. 지울 후보가 없으면 기회를 다시 4번으로.
- 생성기(씨앗 고정): 단어 목록(5·6·7글자 IT 낱말)에서 정답과 후보를 고른다. 후보의 절반 이상은 정답과 일치 1 이상(추리할 거리가 있게).

## 작전 모드에 넣기

- 2장부터 포트 크랙에서 **짝수 번째 포트(2, 4…)는 단어 추리**, 나머지는 브리치 판. 판이 섞여 지루하지 않게.
- 길이: 2장 5글자, 3·4장 6글자, 5장 7글자. 후보 8~10개. 오버클럭 장비 = 기회 +1.

## 사건 파일 모드

- 사건 하나 = 의뢰 + 자료(메일·로그·채팅) + 결론 질문 2~3개.
- 잠긴 자료는 단어 추리로 연다.
- 질문은 하나씩, 고르기. 틀리면 「오답」 표시 후 다시 고를 수 있다. 별: 오답 0개 = 3, 1개 = 2, 2개 이상 = 1.
- 사건 6개. 앞 사건을 풀어야 다음이 열린다. 마지막 사건에서 고스트의 정체가 드러난다.
- 데이터: `assets/cases/c01.json …`. 사람이 읽는 글은 `@열쇠`, 로그·코드는 원문.
- 테스트: 모든 사건의 정답이 선택지 안에 있고, 잠긴 자료의 단어 퍼즐이 만들어지며, 열쇠가 ko.json 에 다 있다.
