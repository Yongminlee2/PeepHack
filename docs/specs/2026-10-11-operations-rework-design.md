# 작전 모드 개편 설계 (재미 개편 2단계)

작성 2026-10-11. 사용자 지시: "묻지 말고 쭉 개발". 1단계 브리치 판(`BreachBoard`)을 포트 크랙에 그대로 쓴다.

## 바뀌는 것

1. **네트워크 지도**: 터미널 위에 임무의 서버들이 선으로 이어진 지도. 집(시작 서버)에서 각 서버로 선. 서버마다 상태 표시 — 지금 있는 곳 / 열림 / 잠김(자물쇠) / 계정 필요.
   - 열린 서버를 누르면 `connect` 를 친 것과 같다.
   - 잠긴 서버를 누르면 선택지: **단서로 접속**(지금처럼 비밀번호·퍼즐·ssh) 또는 **포트 크랙 N개**.
2. **포트 크랙**: 포트 하나 = 브리치 판 하나. N개를 다 뚫으면 그 서버가 열리고 접속된다. 서버 잠금이 퍼즐이었으면 그 퍼즐도 푼 것으로 친다(목표가 그 퍼즐을 요구해도 막히지 않게).
   - 판 실패(별 0·시간 초과) = 추적 +15%, 같은 포트를 새 판으로 다시.
   - 단서를 찾으면 크랙 없이 들어갈 수 있다 → 단서 찾기가 안전한 길, 크랙은 위험한 지름길.
3. **추적 게이지**: 시작 서버를 벗어나 있는 동안 1초마다 오른다. 100% = 들킴 → 임무 실패(다시 / 메시지함).
4. **크레딧·장비**: 임무를 처음 깨면 100, 별이 늘 때마다 별당 50. 브리치 모드는 별이 늘 때마다 별당 10. 상점(메시지함 위 아이콘)에서 장비를 산다.

| 장비 | 값 | 효과 |
|---|---|---|
| 버퍼 확장 | 300 | 크랙 판 버퍼 +1 |
| 오버클럭 | 250 | 크랙 판 제한 시간 +10초 |
| 추적 교란기 | 400 | 추적 오르는 속도 ×0.7 |

## 같이 고치는 구멍

- 계정(`user`)이 있는 서버에 `connect` 로 그냥 들어가지던 것 → `ssh 계정@서버` 를 쓰라는 오류. (3장 ssh 임무가 공짜로 풀렸다.)
